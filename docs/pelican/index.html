这段骑行是怎样做出来的？

画面
所有角色、车架、灯塔和植物均由代码绘制。画布先生成高分辨率贴图，PixiJS 负责分层组织、合成与实时运动。没有预录视频，没有动画 GIF，也没有 SVG 动画。

机械与姿态
轮胎滚动、齿轮传动与脚踏相互联动；脚蹼贴着踏板，双腿通过几何计算弯曲。围巾使用带长度约束的柔性链，跟随风速和身体运动。起跳具有准备、腾空和落地动作。

场景
增加春夏秋冬四季系统。春有花瓣、夏有萤光、秋有落叶、冬有飘雪；季节与昼夜、阵雨可以自由组合。

装扮品阶
装扮分为凡品、良品、上品、珍品、仙品。良品增加旅行包；上品增加勋章与旗带；珍品增加披风和轮组辉光；仙品增加冠羽、光环和星屑拖尾。基础衣服会跟随四季改变颜色与款式。

交互
默认只显示场景切换，其它按钮隐藏。Shift 加速 · 空格起跳 · B 车铃 · P 暂停
